# 🌿 Organic Products Store

## 📌 About the Project

Organic Products Store is a simple and user-friendly website developed using HTML and CSS. It showcases organic products with their names and prices, helping visitors explore the available products.

This project was created to practise front-end web development and demonstrate my understanding of HTML and CSS.

## ✨ Features

- Display organic products
- Show product names and prices
- Customer details form
- Footer section
- Clean and simple user interface

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling and layout

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Find `index.html`.
4. Open `index.html` in your web browser.

## 🎯 Project Objective

The objective of this project is to gain practical experience in front-end development, including creating web page structures, styling product layouts, displaying product information, and building forms.
